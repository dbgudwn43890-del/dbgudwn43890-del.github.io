## Development

When starting the dev server, use background mode:

```
astro dev --background
```

Manage the background server with `astro dev stop`, `astro dev status`, and `astro dev logs`.

## Project context

- This is **Mattally** (`mattally.com`), a US-focused material quantity calculator site built with Astro static output and monetized with AdSense.
- Treat user experience as the primary decision criterion. A calculator merely working is not enough; review whether it is genuinely convenient and clear for a real user.
- Use only free keyword-research sources and tools, such as Google Trends, Google autocomplete, People Also Ask, and Keyword Planner. Do not propose paid tools such as Semrush for this project.
- Do not change the visual design unless the user explicitly asks for design work.

## Communication

- Reply to the user in casual Korean (반말), unless the user asks for a different tone or language.
